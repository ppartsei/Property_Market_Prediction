# Проект прогнозирования высокого спроса объявлений об аренде жилья

---

## Описание проекта

### Бизнес-задача

Стартап StayAI создала платформу, которая позволяет владельцам недвижимости размещать объявления об аренде жилья. Необходимо определить какие объявления будут привлекательными для клиентов и приносить максимальную прибыль платформе.

### Цель проекта

Построить ML-модель для прогнозирования высокого рейтинга новых объявлений без использоваия исторических данных и реализовать производственный пайплайн пакетного инференса с использованием Airflow.

### Подход

Для прогнозирования использована модель CatBoostClassifier. Обучение выполняется на исторических данных с формированием целевой на основе цены рейтинга и количества отзывов. Предсказания модели должны основываться на характеристиках самого объявления, без использования данных полученных от поьзователей. Это необходимо, чтобы модель могла определять перспективные объекты срени новых объявлений без истории отзывов и оценок. Полученная модель сохраняется в S3 и используется в Airflow DAG для регулярного batch-инференса.

## Описание данных

### Таблицы `listings` для десяти городов

Поля:

* 'property_type' - Тип недвижимости: апартаменты, дом, вилла и так далее
* 'room_type' - Тип аренды: целая квартира, комната, отель и так далее
* 'neighbourhood_cleansed' - Район (стандартизованное название)
* 'host_listings_count' - Количество активных объявлений хозяина
* 'latitude', 'longitude' - Координаты объявления, широта и долгота
* 'accommodates' - Максимальное количество гостей
* 'bathrooms' - Количество ванных
* 'bedrooms' - Количество спален
* 'beds' - Количество кроватей
* 'minimum_nights', 'maximum_nights' - Минимальный и максимальный сроки аренды, установленные хозяином прямо сейчас
* 'minimum_minimum_nights', 'maximum_minimum_nights' - Минимум и максимум минимального срока в ближайшие 12 месяцев
* 'minimum_nights_avg_ntm' - Средние значения минимального количества ночей и максимального количества ночей в
ближайшие 12 месяцев
* 'amenities_count' - общее количество удобств у объявления. Посчитано из исходного признака amenities
* 'host_trust_score' - Индекс доверия к профилю. Насколько открыт и заполнен профиль. Посчитанна основе исходных      бинарных признаков: host_verifications + host_identity_verified + host_has_profile_pic.
* 'guests_per_bedroom' - Отношение accommodates к bedrooms. Плотность размещения гостей. Насколько «тесно» будет гостям в этом жилье.
* 'host_has_profile_pic' - Есть ли фото профиля
* 'host_identity_verified' - Верификация личности.
* 'instant_bookable' - Можно ли забронировать без подтверждения хозяина
* 'has_email_verification', 'has_work_email_verification', 'has_phone_verification' - Способы верификации хозяина
* 'is_shared_bathroom' - бинарный признак показывающий, что санузлы общего пользования.
* 'name' - Название объявления
*  'amenities' - Список удобств: Wi-Fi, кухня, парковка и так далее/

## Логика обучения

### Модель

CatBoostClassifier

### Основные гиперпараметры

* learning_rate - 0.06832631781502053
* depth - 6
* l2_leaf_reg - 1.318126573499311

### Метрики качества

* ROC-AUC - 0.8204
* F1 - 0.2555
* Precision - 0.6644
* Recall - 0.1582

## Архитектура пайплайна

### Источники данных

База данных PostgreSQL из десяти таблиц по городам.


### Хранилище артефактов

S3 (Yandex Cloud Object Storage):

* обученная модель CatBoost
* статистики для заполнения пропущенных значений

### Airflow DAG

DAG: `smartscore_batch_inference`

## Инструкция по запуску

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка Airflow Variables

Необходимо создать переменные:

* s3_bucket_name
* s3_access_key
* s3_secret_key
* s3_model_key

### 3. Настройка Airflow Connections

Создайте переменную с ключом smartscore_pg_conn_id и значением postgres_smartscore.

### 4. Размещение DAG

Скопировать файл DAG в директорию:

airflow/dags/


### 5. Запуск

Активировать DAG:

smartscore_batch_inference
